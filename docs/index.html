美元流动性：价格层 vs 数量层

上面两幅是价格/预期层（实际利率、美元指数），最下面是数量层（美联储净流动性）。三幅共用时间轴，悬停可同时查看。阴影是美联储扩表（QE）和缩表（QT）的时期。

拆解：两条恒等式把变化拆到各个来源。实际利率的变化 = 名义收益率的变化 + (−通胀预期的变化)；净流动性的变化 = 总资产（美联储） + (−TGA，财政部) + (−逆回购，货币市场)。哪一项贡献最大，就说明是哪一类因素在起作用。
